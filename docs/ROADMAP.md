# SongTrace Roadmap

This file is a short entry point for contributors. The canonical roadmap lives in [`docs/vision/ROADMAP.md`](vision/ROADMAP.md).

SongTrace's product maturity stages are:

1. **Investigation** — import evidence, extract observations, evaluate deterministic rules, and produce traceable conclusions.
2. **Diagnosis** — evaluate alternative explanations, temporal patterns, contradictions, missing evidence, and confidence.
3. **Decision Support** — produce evidence-backed recommendations and opportunity rankings.
4. **Strategic Advisor** — use explainable AI to synthesize structured SongTrace evidence for human decision-makers.

Near-term development should remain focused on small, deterministic, testable increments. Provider integrations and AI-assisted reasoning should be introduced only after the provider-neutral evidence model justifies them.
